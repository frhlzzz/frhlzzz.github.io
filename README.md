# kipu
Data Knots

My personal portfolio website, built with HTML/CSS/JS and hosted on GitHub Pages.

🔗 **Live site:** https://frhlzzz.github.io/kipu/

## Pages
- `index.html` – Home
- `photos.html` – Photos
- `commissions.html` – Commissions
- `videos.html` – Videos
- `livres.html` – Livres

## Built with
- HTML5, CSS3, vanilla JavaScript

## Running locally
Clone the repo and open `index.html` in your browser, or use a local server (e.g., VS Code's Live Server extension) for the best experience.
